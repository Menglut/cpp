# 프론트엔드 검증 기록

검증일: 2026-09-24. Windows / Node.js 24.12.0 / Codex 브라우저에서 확인했습니다.

## 요구사항 요약과 적용

명세는 C++17 입문자용 한국어 교육 플랫폼을 정의하며, 공개 강의와 문제 탐색, 로그인 후 코드 작성·실행·제출, 개인 기록 및 관리자 콘텐츠 등록을 MVP로 삼습니다. 이번 결과물은 그 사용자 흐름의 프론트엔드 프로토타입입니다. 백엔드가 필요한 부분은 화면에서 모의 기능으로 명시합니다.

## 확인한 항목

- Next.js 프로덕션 빌드 및 TypeScript 검사 통과.
- 홈 → 강의 상세 → 관련 문제 이동.
- 비로그인 제출 버튼 → 로그인 → 학습자 데모 → 원래 문제 복귀.
- Monaco 로컬 로딩, C++ 문법 강조, 키보드 코드 편집.
- 예제 입력의 예시 실행 응답과 모의 제출 결과 구분.
- AC 시나리오 완료, 새로고침 후 제출 결과와 코드 초안 복원.
- AC 후 WA 시나리오를 제출해도 문제 목록의 해결 상태 유지.
- 문제 번호 검색, 검색 쿼리 URL 반영 및 새로고침 복원.
- 난이도 필터의 빈 결과 안내.
- 관리자 데모 접근, 초안 저장 및 새로고침 후 목록 복원.
- Markdown 제목·강조 렌더링 및 원시 script 태그 미실행.
- 390×844 모바일 홈과 문제 풀이: 가로 페이지 넘침 없음, 코드 탭에서 Monaco 표시.
- 코드 초기화 확인창과 Escape 취소.

실제 C++ 컴파일·숨김 테스트·판정 정확성·실행 격리·서버 권한·DB·네트워크 장애 복구는 프론트엔드 프로토타입에 구현하지 않았으므로 검증 완료로 표시하지 않습니다. 관리자 등록 결과의 실제 공개 및 운영 연결도 미구현입니다. 모든 브라우저·모든 화면 크기의 호환성까지 보장하는 검증은 아닙니다.
